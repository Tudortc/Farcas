nirikOP09:43
yeah, we switched last quarter. big win: a failing child cancels its siblings automatically. here's the pattern we settled on 👇
python⧉ copy
async def fetch_all(urls):
    async with asyncio.TaskGroup() as tg:
        tasks = [tg.create_task(fetch(u)) for u in urls]
    # every task awaited; the first error cancels the rest
    return [t.result() for t in tasks]
