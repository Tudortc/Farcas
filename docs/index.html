The wedge

Everything great about a bouncer. None of the pain.

Self-hosting IRC today means The Lounge — a great project that loses people on three specific things. bool is aimed squarely at those.

📱

Working iOS push

An always-on bouncer plus an installable PWA built for notifications that actually arrive on your phone — not just your desktop.

// the #1 reason people leave The Lounge
🔍

Slack-grade search

Full-text search over your entire history with in: / from: / has: filters and surrounding context. Powered by SQLite FTS5.

// find that link from three weeks ago
⚡

Density, done right

Compact by default with a real one-click density toggle. Density is a first-class feature driven by CSS variables — never a hidden CSS hack.

// no more editing stylesheets to fit more rows

Under the hood

A real engine, already running.

bool is a stateful, always-on, private real-time app — deliberately not Next.js. The server-side bouncer works today: multi-user auth and a full IRCv3 engine with encrypted credentials and 59 passing tests.

TypeScript monorepo React 19 + Vite PWA Fastify server irc-framework · IRCv3 + SASL better-sqlite3 + FTS5 Better Auth · multi-user Zustand · react-virtuoso AES-256-GCM secrets at rest
Roadmap

Built in the open, milestone by milestone.

Each milestone ships with its own design spec and plan. Three of eight are done — the chat UI you see above is next up.

M0 · DONE

Foundationshipped

pnpm monorepo, shared typed WebSocket protocol, server + client skeleton.

M1 · DONE

Auth & adminshipped

Better Auth (username + password, sessions), admin panel, session-gated WebSocket.

M2 · DONE

IRC engineshipped

Server-side bouncer — IRCv3 caps, SASL, echo-message, reconnect, encrypted secrets.

M3 · NEXT

History & full-text searchin progress

Persistent messages, retention, and Slack-grade FTS5 search.

M4

Sync gateway & read-state

Multi-device fan-out and synchronized unread state.

M5

Client UI core

The interface above — the four themes, Cmd-K palette, slash commands.

M6

Rich features

Media, reactions, replies, typing indicators — with graceful IRC degradation.

M7
