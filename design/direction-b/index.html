nirikoperator09:43
Yeah, we switched last quarter. The real win: a failing child cancels its siblings automatically. Here's the pattern we settled on —
python⧉ Copy
async def fetch_all(urls):
    async with asyncio.TaskGroup() as tg:
        tasks = [tg.create_task(fetch(u)) for u in urls]
    # every task awaited; the first error cancels the rest
    return [t.result() for t in tasks]
